# Install project skills here manually

Codex discovers repository skills under **`.agents/skills/<skill-name>/SKILL.md`** (plural `agents`). Do not use `.agent/skills/` for native Codex project-skill discovery. This starter deliberately contains **no third-party skill files** or placeholder `SKILL.md` files pretending to be installed. Check each installed skill from a fresh Codex session. See `docs/agent/SKILLS.md`.
